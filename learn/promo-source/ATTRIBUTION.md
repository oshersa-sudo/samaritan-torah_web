# Third-party artwork

The people in the film are composed from **Humaaans** by Pablo Stanley
(https://humaaans.com), obtained from the `humaaans` npm package.

Humaaans is free to use, including commercially, with no attribution required.
This file records the source anyway, so it is clear which artwork in the repo
is ours and which is not.

* `parts/*.svg` — Humaaans body parts, converted from the package's React
  components to plain SVG by `humaaans.py`. The artwork itself is unmodified;
  only React's attribute spelling changes.
* `people.js` — the film's cast, assembled and recoloured from those parts by
  `build_people.py`.

Everything else in the film — the rooms, furniture, phones, captions, timing,
sound design — is original.
