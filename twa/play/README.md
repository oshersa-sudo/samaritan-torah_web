# חומרי הפרסום ל-Google Play

הלוגו החדש ("אבני שהם — התורה השומרונית הישראלית"), חתוך לכל מה ש-Play Console
מבקש. המקור נמצא מחוץ למאגר, בתיקייה `לוגו אפליקציית תורה/exports`.

| קובץ | לאן זה הולך ב-Play Console | הדרישה של גוגל |
|---|---|---|
| `icon-512.png` | Main store listing ← App icon | 512×512, PNG 32-ביט, עד 1MB |
| `feature-graphic-1024x500.png` | Main store listing ← Feature graphic | 1024×500, JPG או PNG 24-ביט |
| `screenshots/01…05` | Main store listing ← Phone screenshots | לפחות 2, 1080×1920 (16:9) |

צילומי המסך צולמו מן האפליקציה עצמה במסך טלפון אמיתי (360×640 נקודות, ×3),
ומראים: רשימת הספרים עם ציון פרשת השבוע והשירון שמתחתיה; פרק באותיות עבריות;
אותו פרק בכתב שומרוני; פירוש הפסוק; והספרייה השומרונית. אפשר לצלם אותם מחדש
בכל עת עם `scripts/play_screenshots.py`.

## אייקון האפליקציה עצמה (לא הפרסום)

האייקון שמותקן על הטלפון אינו נלקח מכאן אלא **מן האתר החי**: `twa-manifest.json`
מפנה אל `/static/img/icon-512.png` ואל `/static/img/icon-maskable-512.png`,
ו-Bubblewrap מוריד אותם בזמן הבנייה. לכן הסדר הוא:

1. לדחוף את הקוד (האייקונים החדשים כבר בתוך `web/static/img/`) ולהמתין
   ש-Render יסיים לפרוס את `main`.
2. להריץ מחדש את בניית ה-TWA: `gh workflow run build-twa.yml --ref main`
   (או לדחוף תג `twa-v*` כדי שה-APK וה-AAB יצורפו ל-release).
3. להעלות את ה-AAB ל-Play Console יחד עם החומרים שכאן.

שים לב: `icon-maskable-512.png` הוא האייקון שאנדרואיד חותך לצורת המסך (עיגול,
ריבוע מעוגל וכו'). לכן המגילה בו מוקטנת ויושבת כולה בתוך מעגל הביטחון (80%),
והרקע ממלא את כל הריבוע — אחרת פינות המגילה היו נחתכות במכשירים מסוימים.
