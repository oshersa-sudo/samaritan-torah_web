## מה נוסף לפרויקט (2026-08-01)

```
web/static/audio/readings/
├── readings.json          ← מניפסט: מיפוי פרק־אודיו ↔ sam_chapters במסד
├── b1-p01-c01.mp3         ← בראשית - בראשית - 1  (בראשית א:א-א:ה)

```

מוסכמת שמות הקבצים: `b{book_id}-p{portion_order:02d}-c{sam_chapter:02d}.mp3`

## מקור וחלוקה

- מקור: הקלטת קריאת בראשית — https://www.youtube.com/watch?v=R_qQhP2mZa4 (12:55)
- החלוקה נעשתה אוטומטית לפי שני סימנים: עצירה ארוכה (0.9–1.7 שנ')
  וירידת המנגינה במשפט האחרון של כל פרק (סיום בגובה ~100Hz לעומת ~132Hz בפסוק רגיל).
- אימות: פרשת בראשית השומרונית (portions.id=1, mode='samaritan') מכסה
  בראשית א:א–ג:כד = בדיוק 17 sam_chapters, וההקלטה התחלקה בדיוק ל-17 קטעים.
  שני הקטעים הארוכים ביותר (6, 13) הם שני הפרקים היחידים בני 8 פסוקים.

## מבנה המניפסט (readings.json)

```json
{
  "book_id": 1,
  "portion": {"id": 1, "name": "בראשית", "mode": "samaritan"},
  "chapters": [
    {
      "n": 1,
      "name": "בראשית - בראשית - 1",
      "sam_ch_id": 1,            // ← מפתח זר ישיר ל-sam_chapters.id במסד
      "verses": "א:א-א:ה",
      "incipit": "בראשית ברא אלהים את",
      "file": "/static/audio/readings/b1-p01-c01.mp3",
      "duration": 38.26
    }, ...
  ]
}
```

**חשוב — מפתח ההצלבה:** ההצלבה נעשית לפי **book_id + sam_ch_number** (מספר
הפרק השומרוני בתוך הספר), לא לפי `sam_ch_id`. ה-id-ים בטבלת `sam_chapters`
נודדים בין עותקי מסד (פיצולים/מיזוגים של אדמין מייצרים id-ים חדשים — במסד
החי של השרת פרק א של בראשית הוא id=1097), ואילו המספרים יציבים. השדה
`sam_ch_id` במניפסט נשמר כמטא-דאטה של מסד המקור בלבד.

## השילוב בצד ה-web — מיושם (2026-08-01)

השילוב כבר בוצע ב-`static/app.js` (גיבוי: `app.js.bak_20260801_readings`)
וב-`static/style.css` (גיבוי: `style.css.bak_20260801_readings`):

1. **טעינת מניפסט** — בטעינת הדף נטען `readings.json`; אם הוא חסר, האפליקציה
   מתנהגת כרגיל (אין שגיאות).
2. **רשת הפרקים השומרוניים** — פרק שיש לו הקלטה מקבל תג ♪ מתחת למספר
   (`renderChapterGrid`, פרמטר `isSam` חדש).
3. **תצוגת הפסוקים** — מעל הפסוקים מופיע פס נגינה (`.reading-bar`) עם כפתור
   ▶/❚❚, פס גרירה (seek) וטיימר. הפונקציות: `readingBar`, `readingToggle`,
   `readingStop`, `readingFor` בסוף app.js.
4. **בלעדיות הדדית** — הפעלת ההקלטה עוצרת TTS ולהפך; ניווט לפרק אחר עוצר
   את הנגינה.

## הרחבה לפרשות הבאות

הצינור המלא נמצא ב-`scripts/reading_pipeline/`:

1. `analyze.py` — הורדת האודיו (yt-dlp), זיהוי עצירות + ירידת מנגינה, הצעת גבולות.
2. בדיקה ידנית עם נגן ה-HTML (bereshit-player.html — כפתורי "מעבר" לכל גבול,
   עורך חיתוך עם כוונון עדין).
3. `prepare_integration.py` — חיתוך, העתקה ל-static, ובניית readings.json
   (יש לעדכן book_id / portion / starts).

בפרשה חדשה: לוודא שמספר הקטעים שנמצאו שווה למספר ה-sam_chapters של הפרשה
במסד — זה מבחן האימות המרכזי.
