# תמונות שניתנו לארכיון

`pix_sources.json` הוא רשימת התמונות שהמסך שבתוך הטייפ מציג **ראשונות**, לפני
אלה שהוא מוצא בעצמו. הוא נועד לתמונות שיש עליהן רשות מפורשת — צלם שאמר כן,
אתר שבעליו אמר כן — ולכן הקרדיט נכתב בו ביד ואינו נלקח משום מקום אוטומטי.

הקובץ אינו חובה. אם הוא ריק, המסך מציג רק את מה שהוא מוצא בוויקיפדיה
ובוויקישיתוף, ושום דבר אינו נשבר.

## המבנה

```json
[
  {
    "src":    "https://live.staticflickr.com/…/….jpg",
    "by":     "אורי אורהוף",
    "lic":    "באישור הצלם",
    "ttl":    "חג הפסח בהר גריזים",
    "source": "Flickr"
  }
]
```

| שדה | מה נכתב בו |
|---|---|
| `src` | כתובת התמונה עצמה. חייבת להיות `https`, וחייבת להיות מוגשת מכתובת שמתירה טעינה מאתר אחר |
| `by` | שם הצלם, כפי שהוא מבקש שייכתב |
| `lic` | הרישיון או תנאי הרשות — למשל `CC BY-SA 4.0`, או `באישור הצלם` |
| `ttl` | תיאור קצר, לא חובה |
| `source` | שם המקור, לא חובה |

הקרדיט המוצג הוא `צילום: <by> · <lic>`.

## מה חסר כדי להוסיף את המקורות שביקשת

**Flickr של אורי אורהוף.** צריך את מזהה המשתמש שלו ב-Flickr (ה-NSID, או כתובת
עמוד התמונות שלו) — ומפתח API של Flickr, או לחלופין רשימת כתובות התמונות
עצמן. בלי אחד מהשניים אין דרך לשאול את Flickr אילו תמונות יש שם. את אישורו
כדאי לשמור בכתב לצד הרשימה.

**the-samaritans.net ו-The Samaritans in Israel.** דפדפן אינו יכול לקרוא את
תוכנן של אתרים אחרים, ואינו יכול להציג מהם תמונות אלא אם האתר עצמו מתיר זאת
במפורש. כדי להביא מהם תמונות צריך אחד מן השניים: רשות בכתב מבעלי האתר ורשימת
כתובות התמונות שתיכנס לכאן, או עותק של התמונות שיישמר בשרת המדיה של הארכיון
עצמו ויוגש ממנו.

**ויקיפדיה — הערך שומרונים.** זה כבר עובד: המסך מביא את תמונות הערך עצמו, עם
שם הצלם והרישיון של כל אחת.
