# העלאת ציר הזמן לאתר the-samaritans.net

האתר בנוי על WordPress (תבנית Astra + Elementor), ואין לי גישה אליו — לכן שני
השלבים האחרונים הם שלך. הכול מוכן ומחכה.

## 1. העלאת התיקייה

העתק את התיקייה `History_timeline` כולה אל שורש האתר, בשם `timeline`, כך שתתקבל
הכתובת:

```
https://www.the-samaritans.net/timeline/
```

אפשר דרך cPanel → File Manager, או ב־FTP. אלה הקבצים הדרושים (ה־`scripts/`
נחוצה רק לבנייה מחדש ואפשר לוותר עליה בשרת):

```
index.html
css/style.css
js/i18n.js  js/chrono.js  js/app.js
data/credits.js  data/periods.js  data/rosters.js  data/events.js  data/i18n_data.js
assets/audio/journey.mp3
```

קובץ המוסיקה שוקל כ־3.8MB, אך מסומן `preload="none"` — הוא יורד רק כשלוחצים
לראשונה על „מסע“, ואינו מכביד על טעינת הדף.

> **חשוב**: אחרי כל עדכון עתידי של קובץ ב־`js/` או ב־`data/` יש להריץ
> `py -3 scripts/bump_version.py` לפני ההעלאה. הדפדפנים שומרים את הקבצים
> במטמון לפי מספר הגרסה שבתגיות `?v=`, ובלעדיו המבקרים ימשיכו לראות את הגרסה הישנה.

## 2. הוספת הפריט לתפריט

בלוח הבקרה של WordPress: **Appearance → Menus**, בוחרים את התפריט הראשי,
ובצד שמאל **Custom Links** → הוספה, כפריט **אחרון** תחת **Who are we ?**:

| שפת האתר | URL | Link Text |
|---|---|---|
| אנגלית (`/`) | `https://www.the-samaritans.net/timeline/?lang=en` | The Historical Timeline |
| עברית (`/he/`) | `https://www.the-samaritans.net/timeline/?lang=he` | ציר הזמן ההיסטורי |
| ערבית (`/ar/`) | `https://www.the-samaritans.net/timeline/?lang=ar` | الخط الزمني التاريخي |

בכל פריט יש לפתוח את **Screen Options** למעלה, לסמן **Link Target**, ואז לסמן
בפריט עצמו **Open link in a new tab** — כך הציר ייפתח בחלון נפרד, כפי שביקשת.

לאחר מכן לגרור את הפריט ימינה כך שיהיה **תת־פריט** של *Who are we ?*, ולמקם
אותו אחרון ברשימה. **Save Menu**.

## 3. מה כבר מטופל מצד הציר

- **בחירת השפה אוטומטית.** הציר קורא את הפרמטר `?lang=`; אם הוא חסר, הוא בודק
  מאיזה נתיב באתר הגיע המבקר (`/he/`, `/ar/` או השורש), אחר כך את הבחירה
  הידנית האחרונה שנשמרה, ולבסוף את שפת הדפדפן. כלומר גם קישור בלי פרמטר יעבוד.
- **חזרה לאתר.** בכותרת יש כפתור „↩ לאתר“, וגם לחיצה על שם המותג מחזירה —
  שניהם מובילים לגרסת האתר בשפה שבה נפתח הציר (`/he/`, `/ar/` או השורש).
- **בורר שפה** בכותרת (עב · EN · ع) למי שרוצה להחליף בתוך הציר.

## 4. חלופה — הרצה מקומית

הציר אינו דורש שרת כלל; אפשר פשוט לפתוח את `index.html` מן הדיסק:

```bash
start index.html
```
