# ציר הזמן ההיסטורי — הישראלים השומרונים

אפליקציית ציר זמן אינטראקטיבית, מבריאת העולם ועד ימינו, המשלבת את תולדות
השומרונים, את תולדות עם ישראל ויהודה, את תקופות השלטון בארץ־ישראל ואת שושלת
הכהנים הגדולים.

## הפעלה

אין צורך בשרת — כל הנתונים נטענים כקבצי `.js` רגילים:

```bash
start index.html
```

ואם רוצים בכל זאת שרת מקומי:

```bash
py -3 -m http.server 8777
```

## הפעולות בציר

| פעולה | תוצאה |
|---|---|
| גרירת **הסרגל האנכי** שמשמאל | מסיעה את ציר הזמן; מציגה את החלק היחסי מן הציר כולו |
| גרירת הציר / גלגלת / ← → | תנועה בזמן |
| `Ctrl` + גלגלת, `+` / `−`, המחוון | שינוי קנה המידה |
| לחיצה על אירוע או על כהן גדול | פתיחת כרטיס עם התיאור המלא והמקור |
| חיפוש | אירוע, אישיות, או שנה בכל אחד משלושת המניינים ("3665 לכניסה", "586-", "1948") |
| `רווח` / כפתור **מסע** | הנעה אוטומטית על הציר |

**נקודת ה־0** היא הקו הזהוב הקבוע בקצה השמאלי: הוא אינו זז, וציר הזמן חולף
תחתיו. לידו מוצגות השנה הגרגוריאנית, השנה לבריאת העולם, השנה לכניסה לארץ כנען,
ושמו של הכהן הגדול שכיהן באותה שנה.

## מניני השנים

מקורם במנוע לוח השנה השומרוני שבפרויקט `samaritan_calendar`:

```
מניין כנען  = שנה גרגוריאנית + 1638      (מאומת מול לוחות אותנטיים)
לבריאת העולם = מניין כנען + 2800          (כפי שנדפס בלוחות)
```

חשבון התורה בנוסח שומרון עצמו — הנשלף ישירות מ־`data/torah.db` — נותן 1307 שנה
מהבריאה למבול, 942 עד לידת אברהם, 430 שנות מגורים בכנען ובמצרים ו־40 שנות מדבר,
כלומר 2794 שנה מן הבריאה עד הכניסה לארץ. מניין הלוח פותח שבע שנים לאחר מכן,
הפרש המיוחס לשנות כיבוש הארץ וחלוקתה.

## מבנה

```
index.html          המסך
css/style.css
js/chrono.js        המרות בין מניני השנים
js/app.js           ציור הציר והאינטראקציה
data/periods.js     תקופות רקע                       (נבנה)
data/rosters.js     כהנים גדולים / ראשי ממשלה / נשיאים (נבנה)
data/events.js      האירועים והאישים                  (נבנה)
data/credits.js     מקורות ואזהרות דיוק
scripts/build_data.py     בונה את data/*.js
scripts/events_data.py    אירועי הספר (מקור לעריכה)
scripts/events_modern.py  אירועי מדינת ישראל, העולם, ומחקר מקוון
scripts/rulers_data.py    ראשי ממשלה ונשיאים
scripts/emit.py           חישוב טווחי הכהונה וכתיבה
```

בנייה מחדש של הנתונים לאחר עריכה:

```bash
py -3 scripts/build_data.py
```

## מקורות ומגבלות

עיקר החומר הוא **בנימים צדקה, "קיצור תולדות הישראלים־השומרונים עפ״י המחקר"**,
שנסרק ב־107 עמודים. **שמונה עמודים (1, 18, 52, 62, 70, 85, 100, 106) נפגמו
בסריקה בטשטוש תנועה ואינם קריאים**, ובהם נדפסו בין השאר הכהנים הגדולים
**56–77, 88–94 ו־103–125**. סריקה חוזרת של אותם עמודים תשלים את החסר; הפערים
מסומנים במפורש ברצועת הכהנים.

המחבר מעיר ש"חלק משנות הכהונה חופפות", ולכן סכימה פשוטה של שנות הכהונה אינה
מתיישבת עם התאריכים ההיסטוריים. הכהנים נפרשו על הציר בין עוגנים שהספר עצמו
מוסר — הכניסה לארץ, שנת 260 לכניסה, גלות אשור, גלות בבל, כיבוש אלכסנדר, צליבת
ישו, אספסיאנוס ואדריאנוס — ומן הכהן ה־95 ואילך הספר נוקב בשנים מפורשות.
**הטווחים המוצגים הם הערכה; שנות הכהונה עצמן מוצגות בכרטיס כפי שנמסרו.**

הכהנים הגדולים שמשנת 2001 ואילך אינם מן הספר (שנחתם בשנת 2000) אלא מאתר מכון המידע
הישראלי־שומרוני, וכך גם סקרי האוכלוסין של 2009, 2013, 2021 ו־2024. המקורות חלוקים
במספרו הסידורי של הכהן הגדול המכהן — 132 לפי המכון, 133 לפי ויקיפדיה, 134 לפי המשך
המספור שבספר — ולכן מוצגים בציר השמות והשנים בלבד.

## שכבות ורצועות

מלבד שכבות האירועים יש שלוש רצועות נושאי משרה: **כהנים גדולים**, **ראשי ממשלת ישראל**
ו**נשיאי ישראל**. רצועה נגלית רק כשהטווח הנצפה נוגע בתקופתה, כך שראשי הממשלה אינם
גוזלים מקום כשמסתכלים על ימי המקרא. נקודת ה־0 מציגה בכל רגע את נושאי המשרה שכיהנו
באותה שנה.
