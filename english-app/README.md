# אפליקציה אישית ללימוד אנגלית – אוצר מילים ומבטא

אפליקציית דפדפן **מקומית לגמרי** להעשרת אוצר המילים והמבטא באנגלית.
אין צורך בשרת, בהתקנה או בחיבור לאינטרנט — כל הנתונים נשמרים במכשיר שלך בלבד
(ב-`localStorage` של הדפדפן).

## הפעלה

פותחים את הקובץ **`index.html`** בדפדפן (מומלץ **Chrome** או **Edge** לתמיכה מלאה בהגייה קולית).
זהו. אפשר גם לשמור אותו כסימנייה או ליצור קיצור דרך בשולחן העבודה.

> טיפ: בפעם הראשונה בכל מכשיר, לחיצה על כפתור ההגייה 🔊 מפעילה את מנוע הדיבור של הדפדפן.

## מה יש באפליקציה

| מסך | תיאור |
|-----|-------|
| 🏠 **בית** | מצב המחזור הנוכחי (שבוע כמה מתוך 4), האוצר הפעיל, ותקציר מהיר. |
| 📖 **אוצר מילים** | 25–30 מילים מתחום משותף: מילה באנגלית, תעתיק הגייה בעברית, תרגום, וכפתור הגייה 🔊. כולל כפתור **🔀 ערבול** לקבלת אוצר אחר. |
| 📝 **מבחן** | מבחן אמריקאי (רב-ברירתי) על האוצר הפעיל, עם משוב מיידי וציון. |
| 📘 **לשון וזמנים** | שיעורי דקדוק וזמנים (הווה, עבר, עתיד, מילות יחס ועוד). נפתח אוטומטית ב-3 הימים הראשונים של כל חודש. |
| 📊 **התקדמות** | כמה מילים נלמדו, כמה שאלות נשאלו, כמה נענו נכון, היסטוריית מבחנים וכיסוי המאגר. |
| 🏛️ **מועצת קלוד** | פאנל יועצים שמנתח את ההתקדמות האישית ונותן המלצות מעשיות + "החלטת מועצה" עם הצעד הבא. |
| ➕ **הרחבה** | הוספת מילים חדשות למאגר (ראו בהמשך). |

## לוח הזמנים – איך זה עובד

- **מחזור = 4 שבועות (28 יום):**
  - שבועות 1–3: לימוד ושינון של אוצר אחד (מתחום משותף).
  - שבוע 4: מבחן אמריקאי על אותו אוצר.
- בסוף כל מחזור המערכת עוברת **אוטומטית** לאוצר הבא, וכך הלאה עד סוף המאגר — ואז חוזרת חלילה.
- **לשון וזמנים:** אחת לחודש, בשלושת הימים הראשונים, מוצג שיעור אחר בכל יום (שלישייה שמתחלפת מדי חודש כדי לכסות בהדרגה את כל הכללים).

חישוב המחזור מבוסס על תאריך תחילת השימוש, שנשמר אוטומטית בפעם הראשונה שנכנסים.

## איך מרחיבים את המאגר (עד 50,000 מילים ומעבר)

המערכת בנויה כך שכל תוספת מחולקת **אוטומטית** לאוצרות של 25 לפי תחום ונכנסת למחזור. שלוש דרכים:

### 1. דרך האפליקציה (הכי קל, בלי קוד)
נכנסים למסך **➕ הרחבה** ומדביקים מילים, באחד משני פורמטים:

**CSV** — שורה לכל מילה: `אנגלית,תעתיק,תרגום,תחום`
```
sugar,שׁוּגֶר,סוכר,kitchen
salt,סוֹלְט,מלח,kitchen
```

**JSON**
```json
[{ "en": "sugar", "pron": "שׁוּגֶר", "he": "סוכר", "cat": "kitchen" }]
```

אפשר גם להעלות קובץ `.csv` / `.json` במקום להדביק. המילים נשמרות במכשיר ומצטרפות למאגר.

### 2. דרך עריכת הקוד (לכמויות גדולות וקבועות)
פותחים את הקובץ **`data/words.js`** ומוסיפים אובייקטים לרשימה `window.WORDS`:
```js
{ en: "sugar", pron: "שׁוּגֶר", he: "סוכר", cat: "kitchen" }
```
זו הדרך המומלצת להוספת אלפי מילים בבת אחת (למשל ייבוא מקובץ מילון).

אפשר גם ליצור קובץ נוסף (כמו `data/words-extra.js`) שמצרף מילים כך:
```js
window.WORDS = (window.WORDS || []).concat([ /* ... מילים ... */ ]);
```
ולהוסיף אותו ל-`index.html` בשורת `<script>` אחרי `words.js`. כך המאגר בנוי כרגע:
`words.js` + `words-extra.js` + `words-extra2.js` = **1,140 מילים ב-22 תחומים**.

### 3. תחומים (categories)
מפתחות התחומים הזמינים: `kitchen, daily, business, conversation, time, tools, body, furniture, objects, vehicles, travel, study, family, food, animals, nature, emotions, professions, clothing, health, verbs, adjectives`.
להוספת תחום חדש — מוסיפים אותו לרשימה `window.CATEGORIES` (ראו דוגמה ב-`data/words-extra2.js` שמוסיף תחומים חדשים דרך `concat`).

## מבנה הפרויקט
```
english-app/
├── index.html          # קובץ ההפעלה
├── css/style.css       # עיצוב
├── data/
│   ├── words.js        # מאגר המילים הבסיסי (13 תחומים)
│   ├── words-extra.js  # הרחבה 1 – עוד מילים ל-13 התחומים
│   ├── words-extra2.js # הרחבה 2 – 9 תחומים חדשים (אוכל, בעלי חיים, טבע ועוד)
│   └── grammar.js      # שיעורי לשון וזמנים
└── js/
    ├── storage.js      # שמירת התקדמות מקומית
    ├── scheduler.js    # לוגיקת המחזורים והדקדוק החודשי
    ├── speech.js       # מנוע ההגייה (Web Speech API)
    ├── council.js      # מועצת קלוד – ניתוח והמלצות
    └── app.js          # ניווט וכל המסכים
```
