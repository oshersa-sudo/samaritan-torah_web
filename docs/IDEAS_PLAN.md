## 2. תכנית יישום (לפי עדיפות)

### שלב 1 — מוטיבציה ותגמול (צד-לקוח, ללא שרת, סיכון נמוך)
- [ ] רצף יומי (streak 🔥) — נשמר לפי טלפון, מוצג בתפריט + תזכורת עדינה
- [ ] נקודות **XP** מצטברות + **רמת שחקן** (מתקדם לפי XP)
- [ ] **תגים** (badges) על אבני-דרך: מבחן ראשון · רצף 3/7/30 · ציון מושלם · 100 מילים נלמדו
- [ ] מסך סיום חגיגי: **1–3 כוכבים** לפי ציון + **קונפטי** + הודעת עידוד מותאמת
- [ ] **מטבעות** על תשובה נכונה (בסיס למערכת פרסים עתידית)

### שלב 2 — התאמה אישית והתקדמות
- [ ] בחירת **אווטאר** (אימוג'י/דמות) שמלווה את התלמיד
- [ ] **מפת מסע** ויזואלית לכל מקצוע (שלבים ננעלים/נפתחים)
- [ ] מצב **"תרגול הטעויות שלי"** — חזרה ממוקדת (spaced repetition) על פריטים שפוספסו
- [ ] **חיות מחמד וירטואליות** שנפתחות עם מטבעות (בהשראת SplashLearn)

### שלב 3 — התאמה וחברתי (חלק דורש את שרת הלמידה)
- [ ] **קושי אדפטיבי** — התאמת רמה תוך כדי לפי אחוז הצלחה (בהשראת DoodleMaths)
- [ ] **מבחן מיקום** ראשוני שקובע רמת פתיחה
- [ ] **לוח מובילים** (דרך השרת שבנינו)
- [ ] **סיכום שבועי להורים** בפורטל + דוחות התקדמות

### שלב 4 — תוכן, גיוון תרגילים ונגישות
- [ ] **הקראה קולית** להוראות ולמילים (עברית/אנגלית, TTS)
- [ ] גיוון תרגילים: **האזנה** (שמע→בחר), **איות** (גרירת אותיות), **גרירת-סדר**, התאמת זוגות
- [ ] הרחבת תוכן: השלמת מילים בעברית, עוד סיפורים, סוגי חשבון נוספים (שברים, זמן, כסף, גאומטריה)
- [ ] מבנה **הרפתקה/סיפור** עוטף (בהשראת Prodigy)
